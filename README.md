# MOLD MASTER — Baking Tools & Accessories

Premium static e-commerce website for Mold Master, focused on baking tools, molds and accessories in Pakistan.

## Included

- Premium responsive homepage
- Shop/product browsing
- Category filtering, search and sorting
- Product detail pages
- LocalStorage cart
- WhatsApp ordering
- About and Contact pages
- GitHub Pages-ready static structure
- Custom 404 page
- `.nojekyll` support

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages

This is a static site. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
